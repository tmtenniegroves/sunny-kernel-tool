# sunny-kernel-tool

Engineering manager · dev productivity · building tiny tools

折腾中的小玩具

## 用法

```bash
cat data.txt | ./run.sh
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/sunny-kernel-tool.git
cd sunny-kernel-tool
chmod +x run.sh
```
